# 📌 Team Task Manager (Full-Stack MERN App)

A full-stack role-based task and project management web application where users can create projects, assign tasks, and track progress efficiently.

## ✨ Features

### 🔐 Authentication
- User Signup & Login
- JWT-based authentication
- Password encryption using bcrypt

### 👥 Role-Based Access
- Admin & Member roles
- Admin can manage projects and members
- Members can view and update tasks

### 📁 Project Management
- Create projects
- Add/remove members
- View project details

### ✅ Task Management
- Create tasks
- Assign tasks to users
- Update task status (Pending / Completed)
- Due date tracking

### 📊 Dashboard
- Total tasks
- Completed tasks
- Pending tasks
- Overdue tasks
